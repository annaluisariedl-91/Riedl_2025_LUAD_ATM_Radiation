# Riedl_2025_LUAD_ATM_Radiation
This repository contains all R scripts and workflows used for the analysis of functional assays, transcriptome (RNA-seq), and proteome data from lung adenocarcinoma (LUAD) cell lines with different ATM status. The project investigates how ATM deficiency modulates the cellular response to irradiation and ATM inhibition (AZD1390).
